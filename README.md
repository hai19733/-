## 🧠 平台（比如币安）到底是什么？（中性科普）
你可以把它理解为一种“数字资产服务平台”，提供账户体系、资产管理与多端访问能力。  
新手最容易踩坑的不是“不会用”，而是：**入口不对、被钓鱼、把验证码给了别人**。

## ✅ 三条底线
1) 任何人要验证码/助记词/私钥：直接拉黑  
2) 不点私聊链接/短链接/网盘转存包  
3) 看不懂的授权/签名不要点
